## MCP connection facts

- Endpoint: `/mcp` on the Coroot instance.
- Interactive clients (Claude Code, Cursor, Codex) authenticate with OAuth 2.0.
- Headless or autonomous agents authenticate with an API key sent as `Authorization: Bearer <api key>`.
